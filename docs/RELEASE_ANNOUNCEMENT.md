## 🎯 The Ultimate Bullet Hell Game is Here!

Avoid Bubble is a cross-platform bullet hell survival game built with Flutter and Flame engine. Play instantly in your web browser and survive as long as possible while dodging increasingly challenging 3-stage bullet patterns!

## ✨ 상세 특징

### 🎯 3단계 탄막 시스템

- **1단계 (2-15초)**: 플레이어를 추적하는 타겟팅 탄막
- **2단계 (15초+)**: 8방향에서 동시 공격하는 집중 탄막
- **3단계 (30초+)**: 화면을 가로지르는 연속 직선 탄막

### 🏆 등급 시스템

- 🏆 **S등급**: 5분 이상 (300초+)
- 🥇 **A등급**: 3-5분 (200-299초)
- 🥈 **B등급**: 2.5-3분 (150-199초)
- 🥉 **C등급**: 1.5-2.5분 (100-149초)
- 📜 **D등급**: 1-1.5분 (50-99초)
- 😵 **F등급**: 1분 미만 (50초 미만)

### 🌍 완전한 다국어 지원

- 한국어 / English 자동 감지
- 브라우저 언어에 따른 자동 설정
- 모든 UI 텍스트 완벽 번역

## ✨ Key Features (English)

### 🎯 3-Stage Bullet System

- **Stage 1 (2-15s)**: Targeted bullets that track your position
- **Stage 2 (15s+)**: 8-directional simultaneous attacks
- **Stage 3 (30s+)**: Sequential linear bullet walls

### 🏆 New Challenging Grade System

Updated with more challenging and meaningful grade criteria:

- 🏆 **S-Rank**: 5+ minutes (300+ seconds)
- 🥇 **A-Rank**: 3-5 minutes (200-299 seconds)
- 🥈 **B-Rank**: 2.5-3 minutes (150-199 seconds)
- 🥉 **C-Rank**: 1.5-2.5 minutes (100-149 seconds)
- 📜 **D-Rank**: 1-1.5 minutes (50-99 seconds)
- 😵 **F-Rank**: Under 1 minute (50 seconds)

### 🌍 Full Internationalization Support

- Korean / English automatic detection
- Browser language-based automatic setup
- Perfect translation of all UI text

### 🎮 Game Controls

#### Keyboard
- **Movement**: WASD keys or Arrow keys
- **Restart**: R key (instant restart anytime)
- **Main Menu**: ESC key

#### Mobile/Touch
- **Joystick Support**: Smooth joystick control

#### Audio Options
- **Background Music**: Immersive gameplay experience
